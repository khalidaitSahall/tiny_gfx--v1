TinyGFX — محرر البلوكات (16×16) ولوحة 256 لوناً

محرر رسومي وخفيف مبني من الصفر بلغة C++17 بدون أي مكتبات خارجية لتحرير البلوكات (16×16) ضمن شبكة (16×16) ولوحة ألوان (256 لوناً)، مع رسم مباشر في الـ Framebuffer، وخط نقطي 5×7 مدمج بدون وميض، وتحكم بالماوس والأوامر النصية، وتصدير الصور بصيغتي BMP و PPM.

C++17 Zero External Dependencies Windows (Win32 + GDI) | Linux (X11)

Lightweight zero-dependency C++17 16×16 block & 256-color tileset editor with direct 32-bit framebuffer rendering, flicker-free 5×7 bitmap font, mouse & command input, and BMP/PPM export.

المزايا الرئيسية | Key Features

  • بدون مكتبات خارجية: كود C++17 مباشر يستدعي واجهة النظام (Win32 API + GDI على Windows وX11 على Linux).
  • واجهة بدون وميض وخط 5×7: تُرسم عناصر الواجهة والأوامر وحالة الحفظ ودليل الأوامر داخل الـ Framebuffer قبل عرض الإطار.
  • بلوكات 16×16 ولوحة 256 لوناً: 1,000 بلوك بقياس 16×16 مرتبطة بلوحة ألوان من 256 لوناً.
  • ماوس + أوامر سريعة: الرسم والمسح بالماوس، وتبديل البلوكات بالعجلة، وتنفيذ أوامر مختصرة عبر الكيبورد.
  • تصدير الصور: حفظ الصور بصيغة BMP (الافتراضي output.bmp) وPPM (الافتراضي output.ppm).

هيكل المشروع | Project Structure

project/
├── tiny_gfx.hpp          # الواجهة الموحدة متعددة المنصات | Cross-platform API
├── platform_win32.cpp    # تنفيذ Windows (Win32 + StretchDIBits + خط 5x7)
├── platform_x11.cpp      # تنفيذ Linux (X11 + XPutImage)
├── ext_tileset.hpp       # منطق البلوكات 16x16 ولوحة الـ 256 لوناً
├── main.cpp              # حلقة المحرر، الأوامر، الشرح، وتصدير BMP/PPM
└── README.html           # صفحة التوثيق

الترجمة والتشغيل | Build & Run

Windows (MinGW / g++):

g++ -O2 -std=c++17 main.cpp platform_win32.cpp -lgdi32 -o editor.exe
.\editor.exe

Linux (g++ + X11):

g++ -O2 -std=c++17 main.cpp platform_x11.cpp -lX11 -o editor
./editor

التحكم والأوامر | Controls & Commands

  • الزر الأيسر للماوس: تلوين الخانة بالبلوك النشط.
  • الزر الأيمن للماوس: تفريغ الخانة وإعادتها إلى 0.
  • عجلة الماوس (Scroll): التنقل بين أرقام البلوكات النشطة.
الأمر الكامل الاختصار الوظيفة | Description
brush <id>b <id>اختيار رقم البلوك النشط | Select active block ID
set <x> <y> <id>s <x> <y> <id>تعيين بلوك في الخانة (x, y) | Set cell block
fill <id>f <id>تعبئة شبكة 16×16 بالبلوك | Fill 16×16 grid
clearxمسح كامل الشبكة | Clear entire grid
paint <pal>p <pal>تلوين البلوك الحالي بلون اللوحة (0..255) | Paint palette index
rgb <r> <g> <b>c <r> <g> <b>تعديل لون RGB للبلوك النشط | Set active block RGB
bmp [file]m [file]حفظ صورة BMP (افتراضي output.bmp) | Export BMP
ppm [file]i [file]حفظ صورة PPM (افتراضي output.ppm) | Export PPM

قواعد الثبات وأين تضع الميزات الجديدة | Stability & Extension Rules

  • الرسم قبل EndDrawing(): اجعل كل النصوص واللوحات داخل BeginDrawing() ... EndDrawing() لتجنب الوميض.
  • عدم تضمين ترويسات النظام في tiny_gfx.hpp: أبقِه واجهة نقية مستقلة عن Windows وX11.
  • الحفاظ على ترتيب BMP: ارتفاع سالب في BITMAPINFO (-height)، ومحاذاة الأسطر إلى 4 بايت، وكتابة البكسلات من الأسفل للأعلى بترتيب B, G, R.
  • توزيع الميزات: دوال الرسم والمدخلات في tiny_gfx.hpp + platform_*.cpp، والبلوكات والألوان في ext_tileset.hpp، والأوامر والملفات في main.cpp.
